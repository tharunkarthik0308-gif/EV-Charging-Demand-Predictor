# EV Charging Demand Predictor - React Frontend

Vite-based React TypeScript application styled with Tailwind CSS and charting via Recharts.

## Prerequisites
- Node.js (v18 or higher)
- npm or yarn package manager

## Development Setup
1. Duplicate `.env.example` as `.env`:
   ```bash
   cp .env.example .env
   ```
2. Install npm dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Access the portal at [http://localhost:5173](http://localhost:5173)
